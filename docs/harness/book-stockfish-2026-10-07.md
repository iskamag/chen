# Opening book — Stockfish 19 configured 1800, 0.5 s and 1.0 s

Descriptive offline match of the CPU engine **with the opening book enabled**
against Stockfish 19 configured 1800, at 0.5 s and 1.0 s per move. This measures
the bot as played with the book; it is **not** a Lichess rating and not an
isolated measure of the book's effect. Generated by
[`scripts/match.py`](../../scripts/match.py) (python-chess 1.11.2).

## Setup

- **Candidate:** `target/release/chen`, `Backend=alphabeta`, `Eval=tapered`,
  `Level=20`, `Hash=16`, `Book=true`, `BookSeed=0`, `BookPlies=12`. All other
  search controls at their defaults (TT, quiescence, ordering on; PVS off).
  `BookSeed=0` makes book choice the most common move, so the run is
  reproducible.
- **Opponent:** Stockfish 19 universal, `Threads=1`, `Hash=16`,
  `NumaPolicy=none`, `UCI_LimitStrength=true`, `UCI_Elo=1800`,
  `SyzygyProbeLimit=0`, bundled NNUE, no tablebase adjudication.
- **Openings:** the eight authored controls (Italian, Ruy Lopez, Scotch, Four
  Knights, Petrov, Vienna, Open Sicilian, Alapin Sicilian), each played with
  colors swapped — 8 complete pairs per lane. These are correlated,
  project-authored lines; no independence is asserted.
- **Budget:** one second and half a second per move, `max-plies=300`, draw
  claims enabled.

## Results

| Budget | W / D / L | Points / games | Score | Relative Elo |
| --- | --- | ---: | ---: | ---: |
| 0.5 s | 8 / 4 / 4 | 10.0 / 16 | 0.625 | **+88.7** |
| 1.0 s | 7 / 4 / 5 | 9.0 / 16 | 0.5625 | **+43.7** |

Both lanes: 8 completed pairs, 0 incomplete, 0 technical failures. Terminations
were checkmate (12) or threefold repetition (4) per lane; no caps.

`Relative Elo` is the harness's logistic point estimate for the candidate versus
the tested opponent under this workload. It is not a Lichess rating, and the
configured-setting proxy of the opponent is not a calibrated 1800.

## Book usage

The book moved on only 16 (0.5 s) and 18 (1.0 s) of Chen's plies across a whole
lane (2–3%). The authored openings start at move 4 (ply 7), and Chen leaves the
named book lines within a few plies of that, so this run mostly measures the
engine; the book barely engaged. A book-on versus book-off pair at the same
budget would be needed to isolate the book's effect.

For loose context only, the earlier CPU reference default (PVS off, no book)
scored 5 / 2 / 9 against the same opponent at one second
([current CPU reference](cpu-rating-current-2026-10-03.md)); this run scored
7 / 4 / 5. The opening set and budget match, but the binary, sample size and
opening correlation do not support a strength claim.
