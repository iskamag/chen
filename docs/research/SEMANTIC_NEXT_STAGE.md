# Next semantic comparison: declaration requirements

This is a review checklist for the next experiment, not an authorization to
train or inspect heldout scores. Bounded strong-label production and GPU
corpus/training are separate milestones. The current representation source is
on neural branch `2a08ebb`; the reviewed packet-v2 producer and representation
dependencies are frozen in the tracked packet-v2 preparation archive. Its [closed teacher attempt](evidence/semantic-teacher-packet-v2-2026-10-01/README.md)
retained 233/62/55 whole families and passed independent mechanical audit.
The corpus serialization and TRAIN GPU mechanics are sealed and verified; the
learning declaration remains unsealed.
The [resident corpus contract](SEMANTIC_RESIDENT_CORPUS.md) describes
exact state/history ownership, complete-root batching, intervals and split
isolation, its implemented packer and actual TRAIN GPU admission. The model
comparison harness is under development in the neural worktree.

## Freeze data and units

Pin the accepted whole families, all query records, source modules and Stockfish
score-frame configuration. Keep rejected families without replacement. Join
every root's complete legal child support by canonical action and exact
simulator identity/history; retain the distinction between schema1 features
and simulator history sidecars. Test labels must stay sealed from the training
loader until selection and source/checkpoint fingerprints are frozen.

Predeclare an interval-aware objective and bounds for fitting **one positive
material-unit scale on TRAIN standalone labels only**. Reuse it across all
representation controls. Keep the raw pawn-100 material and raw Tapered
baselines visible; any separate static calibration needs its own declaration.

Parent MultiPV labels supervise complete-root choices. Standalone labels
supervise scalar calibration. The common approximate material frame changes
units; the two query kinds still have different search contexts, node budgets
and reported horizons. If absolute parent-PV transition supervision is used,
declare that query kind and report its disagreement with refreshed standalone
evaluation. Neither label kind is exact minimax ground truth.

## Compare representations and transitions

Compare square, relation, plan and independent threat encoders with the declared
width/depth and common eight-role decoder protocol. Use paired seeds, shared
initialization where structures match, identical sample IDs and equal optimizer
update counts. Record active/stored parameters and actual times; this does not
establish equal computation across architectures.

Pretrain anchors using TRAIN semantic reconstruction plus TRAIN standalone
value labels. Freeze and fingerprint each anchor/readout before transition
training. Conditioned and role-transport controls receive the same exact child
priors and common transition initialization. The blind control computes its
root residual once and expands it across siblings, preserving exact ties for
same-material actions. A shuffle control must hold the true anchor fixed and
declare exactly which action-dependent input is shuffled.

Multi-step evaluation must state where the simulator refreshes exact state or
features and where predicted plans continue without refresh. Hybrid simulated
state plus transported plans is distinct from wholly imagined latent history.

## Seal selection before test

The training declaration still needs concrete seeds, update counts, sample
ordering, loss coefficients, optimizer, refresh schedules, and wall/resource
ceilings. Declare scalar interval error, complete-root regret/agreement,
transport drift and baseline comparisons before running them. Use a joint
validation gate for error and root-choice quality against the specified
material and Tapered controls. A failed gate selects no model.

Freeze the selected configuration, checkpoint and executable source hashes
before the single test pass. Do not rescore, retrain or replace test families
afterward. Numerical/mechanical success, test error and paired playing strength
remain separate evidence, and none alone establishes 2500 Lichess.
