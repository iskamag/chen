# A supervised strategy bottleneck and causal plan correction

This is a new **untrained** architecture experiment. The ce63edd strategic study selected no model: action directions improved on a narrow same-material diagnostic, but learned gaps were about73cp against teacher329cp and no configuration passed both calibration and complete-root ranking gates. Its frozen latent target was a random initialization. This module replaces that target with a representation pretrained on training families only, and tests an independent typed piece-relation encoder alongside the preserved square/relation/plan encoders. There is no strength or globally new architecture claim.

Implementation: [semantic_strategy.py](../neural/semantic_strategy.py); CPU oracle and mechanics checks: [test_semantic_strategy.py](../neural/tests/test_semantic_strategy.py). This format is separate from existing deployment artifacts. It does not modify old models, checkpoints or production search.

## State and API

`SemanticAnchor(encoder, width, depth, material_scale, anchor_kind)` supports `square`, `relation`, `plan`, and independent `threat`. `encode(features)` maps schema1 float32 `[B,18,8,8]` to eight plan tokens `[B,8,D]`. All four backends use the same eight-query pooling, semantic decoders and scalar readout. The old backends retain their encoder mathematics; their unused original output/dynamics heads are excluded from `active_parameters()`.

The `threat` backend treats occupied squares as piece objects, with piece/rule features and explicit normalized file/rank coordinates. Directed blocker-aware attack edges distinguish own attack, own support, enemy attack and enemy support. Each message block averages each relation type's sender messages separately and updates the receiver object. Empty squares cannot send or retain object messages. Eight learned queries pool the objects into the supervised plan bottleneck. This uses no Stockfish or NNUE network design or weights.

The blocked relations are **hand-provided chess diagram priors**. The representation, query pooling, relation messages, semantic reconstruction and score correction are learned. The anchor does not ingest the eight semantic target maps themselves. Relations overlap with those targets, so successful reconstruction alone cannot establish learned tactical reasoning. Sharing a decoder shape does not match parameter count or execution cost: `parameter_counts()` reports total and active parameters; the study must also measure runtime and retained state separately.

`forward(features)` returns `latent`, `pieces`, `value_cp`, `residual_cp`, `material_cp`, `utility`, `board_logits[B,13,8,8]`, `map_logits[B,8,8,8]`, `castling_logits[B,4]`, `ep_logits[B,65]`, and `halfmove[B]`. Every learned output passes through the eight tokens. Material is the declared external arithmetic prior, not a latent-decoder bypass hidden from the report.

## Eight diagram semantics

Tokens are paired own/enemy and supervised by eight corresponding map heads:

| Pair | Target definition |
| --- | --- |
| King pressure | Opponent blocked pseudoattack count, restricted to the king's square and adjacent squares; counts clipped to8 and divided by8. |
| Loose pieces | Nonking occupied squares attacked by the opposite side and defended by no piece of the same side, including king/pawn defence. Binary. |
| Pseudoattack coverage | Same-side blocked pseudoattack count at each target square, clipped to8 and divided by8. |
| Pawn advance | Empty one-step forward destination of a same-side pawn, ignoring pins, check, promotion choice and double steps. Binary. |

Pseudoattacks include defended friendly-occupied endpoints and attacks by pinned pieces. Sliding blockers exclude both ray endpoints. They do not prove a legal capture, winning threat, safe king move, legal pawn advance, or opponent best reply. No capture-value exchange analysis is smuggled into these labels. Adversarial fixtures include a pinned knight, blockers, both colors, and same-material positions.

Additional targets are empty-plus12-piece board classes, four canonical castling rights, raw EP square or no-EP65th class, and the schema1 halfmove clock clipped at100. Schema1 omits fullmove/repetition history; decoding it cannot recover these. `anchor_losses()` returns **unweighted** resident components; the study must freeze loss coefficients, teacher masks, sampling, seeds and data provenance before training. A zero ordinary-mask batch has zero scalar loss while retaining declared diagram losses.

## Scalar calibration and teacher contract

The scalar is **reference-material58 approximate CP-like units**, from declared finite-node selective SF19 teacher scores, never WDL or game outcome probability. The single head predicts an unconstrained correction times800, added to a declared material prior if `anchor_kind='material'`; `utility=tanh(value_cp/800)` is only a compression diagnostic. Calibration and sibling ranking must use this same unconstrained scalar, with parent choosing the **lowest child-mover CP**. Terminal/mate/bound labels must be explicitly excluded from ordinary scalar loss, rather than silently saturated into ordinary examples.

Physical material uses exact schema1 pawn100/knight320/bishop330/rook500/queen900/king0 arithmetic, clipped to±29000 before optional scaling. Stockfish UCI normalized CP is a different scale and changes with the queried root material. A positive `material_scale` may be fitted to the common reference-frame training labels only, persisted, frozen before validation/test, and shared with every scaled-material/static control. Original unscaled pawn100 material remains a separate control. The default scale1 is a mechanical fixture, not a fitted value. Zero-anchor experiments keep the same learned head and explicitly remove the arithmetic prior.

The external teacher is selective finite-node Stockfish search. **Negation alone is insufficient**: SF19 normalizes ordinary reported CP using the material of the query root. A parent MultiPV score remains parent-normalized even when its principal variation starts with a capture or promotion. A standalone child query uses the child material, so those raw numbers cannot silently share a calibration target.

[score_frames.py](../neural/score_frames.py) pins the official sf_19 reporting equation and source hashes. Let total root material use P/N/B/R/Q/K weights1/3/3/5/9/0 across BOTH sides, let `m=clamp(material,17,78)/58`, and let `a(m)` be the pinned cubic with coefficients `[-142.72052667,372.35176398,-340.71073572,415.23490212]`. SF19 reports `c=std::round(100*internal/a(m))`, with nearest-half-away-from-zero rounding. The common midpoint is `c*a(m)/a(1)` and its reporting quantization halfwidth is `0.5*a(m)/a(1)`. A small declared numerical guard makes a conservative closed interval; the resident float32 midpoint also includes its casting error in an outward-rounded halfwidth. This recovers an **interval**, not an exact hidden internal score or statistical confidence interval.

Convert standalone child labels using that actual **child query root**. Convert parent MultiPV labels using the actual **parent query root**, then negate midpoint and reverse/negate interval bounds for child-mover perspective. Every candidate within one parent shares a positive normalization factor, preserving ranking and ties. Retain original integer UCI CP, query-root material, source score kind, multiplier, midpoint, halfwidth and conversion manifest. The phase-tagged checkpoint config embeds the exact score-frame contract; `target_kind=sf19_reference_material58_approx_cp`.

`anchor_losses(..., teacher_halfwidth=...)` uses normalized SmoothL1 on distance **outside** the declared interval; predictions inside it incur zero scalar loss. Default zero width is only for synthetic/exact mechanics targets. The study must supply converted halfwidths for SF labels and admit nonnegative finite widths. `interval_smooth_l1` is also available for transition value losses. It accounts only for reporting uncertainty, not selective-search error. Do not treat rounding-width intervals as calibration confidence or promote a model because this sub-CP reporting loss changes.

MultiPV scores at a common completed depth are search estimates; they must not be called exact fixed-depth full-width minimax. Standalone queries and parent MultiPV have different node budgets, root competition and effective horizons even after their units are aligned. Their differences remain search-procedure differences, not a conversion bug. Mate/tablebase/upperbound/lowerbound scores are a separate source kind and must be excluded BEFORE conversion; a UCI `cp` token by itself cannot certify ordinary internal units. The helper requires an explicit admitted ordinary-unbounded-no-tablebase kind and does not inspect hidden engine state. Checkpoint provenance records the producer, node/depth/mate/bound handling, game-family split and train-fitted scale. Source PGN outcomes are not these labels.

## Frozen transition and controlled routing

`SemanticTransition(anchor, mode)` freezes all anchor parameters, including its value and semantic decoders. `predict(root_features, canonical_actions, root_latent=None)` accepts **no observed successor features**. Standard-chess simulator-certified legal actions are encoded as `(source*64+target)*5+promotion`, canonical to the current mover. Exact existing piece algebra handles capture, EP, castling and promotion, then flips ranks and colors into child-mover perspective. It reconstructs piece planes only; rights, clocks and history remain simulator-owned.

The root plans change roles using `[1,0,3,2,5,4,7,6]`. A learned event embeds source/destination/captured pieces, promotion and endpoint coordinates. A learned correction combines those events, oriented plans and attention over the exactly derived child diagram. The predicted plans feed the **same frozen decoder** as a fully observed refresh. A weak pretrained readout can limit the transition; anchor quality must be measured before interpreting transition gains.

All three modes construct identical state keys and consume the same initialization RNG. Clone one common state for controlled comparisons:

- `transport`: role-conditioned attention adds each role's exact child semantic map as a fixed routing bias.
- `conditioned`: receives identical child pieces, maps and move event, but omits the fixed role routing bias.
- `action_blind`: learned correction sees oriented root plans only; the declared material anchor still sees the real move.

Here transport means **routing strategic plan correction**, not moving eight tokens like pieces. Both action-conditioned modes receive the same exact child prior, removing the earlier root-vs-child diagram input confound. Fixed routing itself is a stronger hand prior; any gain is evidence for this composition, not discovery of attack rules. `active_parameters()` excludes irrelevant mode branches. Report active counts even though stored states match.

`branch(root_features[B], actions[B,K], root_latent=None)` encodes each root once. For the blind control it also computes each root's learned latent and residual once, then expands across candidates and adds the true candidate material. Same-material blind siblings therefore have exact equal predictions, avoiding duplicate-root microCP batch artifacts seen in the prior study. Group by legal count or use explicit external ragged scheduling; padded/illegal/null actions are unsupported.

Root-cache identity includes feature schema, exact canonical input bytes, complete anchor/transition weight version and fitted scale. The optional tensor cache API checks shape/device/dtype only: the caller must enforce that identity; arbitrary same-shaped tensors are not certified to belong to the current root. Cache only neural observations; separate simulator context, epoch, full rules and history govern legal support and teacher labels. Reusing equal feature bytes across different histories preserves the neural prediction but does not make their legal/search contexts equivalent. A cached latent must match batch/device/width; invalidating model weights invalidates the cache.

## Multi-step scope and target separation

`rollout(observations[T,B,18,8,8], actions[T,B])` is explicitly hybrid. It encodes ply0 once, propagates predicted strategic plans with gradients, and reads simulator-provided **current** piece/rule sidecars for each next move's local algebra. It does not re-encode an intermediate or successor observation. This permits strategic correction under legal move sequences, not autonomous neural state simulation. An entirely imagined rule/history rollout is a separate experiment.

Successor anchor encodings and semantic/value labels may appear only in a detached/frozen loss target branch. Train that anchor on training game families, freeze it before transition training, and never fit it on validation/test states. Family and canonical-feature disjointness, including predecessor/successor alias checks, are producer responsibilities. Separate train-only anchor fitting from transition optimization and record both weight hashes. The module cannot infer data provenance from tensors and does not certify a caller's split.

Evaluation should compare predicted vs full-refresh CP/semantics, successor plan refresh error, same-material sibling gap direction **and magnitude**, true-action vs shuffled-learned-residual sensitivity retaining the real anchor, complete-support selected-action regret, blocker/tempo/reply interventions, and two/four-ply hybrid accumulation. Stronger semantic reconstruction does not establish improved reply prediction or search strength. Simulator terminals, mates, draw claims and legal support override any learned score.

## Persistence and verification

`save_semantic_checkpoint` / `load_semantic_checkpoint` use a new phase-tagged `chen_semantic_strategy_checkpoint`, version1. Restricted CPU-first loading bounds file size at128MiB, checks exact envelope/config/tensor keys, shape/dtype/finite values, and compares all deterministic graph/orientation/material buffers to a fresh model before strict loading. JSON config equality rejects boolean integer aliases. Provenance is primitive finite JSON. These checkpoints are not accepted by the old inference exporter or deployment manifest; deployment would need a separate reviewed contract.

CPU checks cover all four encoders, gradients through typed messages and semantic heads, unused old-head exclusion, no tensor scalar extraction in forward/loss/prediction, oracle blocked attacks/pawn advances, special-move piece effects and child sign, shared initialization, exact blind cached ties, frozen readout with differentiable correction, four-ply hybrid absence of hidden refresh, and malformed checkpoint rejection. Small synthetic updates test optimizer mechanics only. Four additional CPU score-frame tests independently use decimal polynomial arithmetic and half-away rounding to check interval recovery, root-vs-child capture/promotion normalization, sign/bound reversal, material clamps, parent ranking invariance, resident outward widths, no scalar extraction, interval gradients and invalid source kinds. No GPU timing, trained heldout result or strength evidence is claimed by this architecture stage.

The composition builds on [graph-network relational biases](https://arxiv.org/abs/1806.01261) and [attention](https://arxiv.org/abs/1706.03762). [Self-Predictive Representations](https://arxiv.org/abs/2007.05929) motivates predicting future representations; our frozen train-supervised semantic target differs from its RL target procedure. [Value Equivalence](https://arxiv.org/abs/2011.03506) motivates evaluating predictive representations by decision-relevant values. None of these sources establishes originality or success of Chen's eight-role architecture; those are testable local hypotheses.
