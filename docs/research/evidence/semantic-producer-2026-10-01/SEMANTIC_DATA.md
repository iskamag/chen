# Real-game inputs and bounded strong-teacher protocol

This stage replaces synthetic random walks with actual rated games and proposes stronger finite-node search labels. Only archive acquisition, CPU admission, source inspection, and fabricated-UCI protocol tests have run. There are **no real teacher labels, GPU corpus, learned results, or rating claims** in this milestone.

The official [Lichess database](https://database.lichess.org/) releases these games under CC0. We acquired the complete January 2013 standard-rated monthly shard, rather than a truncated compressed range: 121,332 games, 17,761,302 compressed bytes. Its SHA256 is `aa40b3671fa3cf1072eb182892cd90b0e1e003a4a5943492f64b77e7f3fd1635`, matching the publisher's [checksum list](https://database.lichess.org/standard/sha256sums.txt). Decompression yields 92,811,021 bytes with locally derived SHA256 `8963b6a1620a0e9c77e5515a0744ec133e86869487188af047bb0a74400dee37`. The decoder verifies both pins before accepting an existing local file. Acquisition has explicit 32 MiB compressed and 256 MiB decoded bounds.

Admission keeps standard starting positions, rated games, both recorded ratings at least 1800, and time controls whose base seconds plus forty increments are at least 180 seconds. Games must contain at least 73 legal plies and at most 512. PGN results, comments, and embedded evaluations are never targets or model inputs. Ratings select inputs; they do not establish the strength of this engine. This old population, shared players, and shared unobserved opening ancestry remain limitations.

We order games by SHA256 of `20261007:game_id`, where game_id is the SHA256 of the canonical eight-character Lichess site URL. An entire game family is admitted or rejected. For base observation plies 16/24/32/40/48/56/64/72, add `(observation_index + game_id_last_hex_parity) % 2`. Each game therefore supplies four actual White-to-move and four Black-to-move observations. Its one full-action root is ply `32 + game_parity`.

The first draft used only even plies. That issue was found **before scores, training, or model metrics**. Its [unscored admission](../neural/evidence/semantic-data-unscored-admission-revision1-2026-10-01.json.gz) and [executed source](../neural/evidence/semantic-data-admission-revision1-source-2026-10-01.py) are retained. This revision is a correction of input sampling, not reuse of a trained or consumed test set.

The corrected [admission summary](../neural/evidence/semantic-data-admission-2026-10-01.json) and [full compressed provenance](../neural/evidence/semantic-data-admission-2026-10-01.json.gz) record these actual counts:

Scanning all 121,332 headers left 5,017 candidates. While filling families, admission rejected 436 short games and one cross-game canonical collision. It completed in 29.10 seconds on the host CPU. Source records retain exact raw-EP FENs, full game moves, source byte ranges and SHA256, observation prefixes, and simulator-compatible prior position hashes.

All selected observations and every root child are included in collision admission. Equivalence uses the actual schema1 representation: own/enemy piece planes, mover rank flip, castling, raw EP, and clipped halfmove clock; fullmove and repetition are absent. No split overlaps another or any of 751,183 canonical keys from seven pinned spent-input reports. Those reports include the completed negative strategic study and its CPU action-blind diagnostic. Repetition history remains a simulator/search sidecar, not an encoder feature. Disjointness covers the admitted model inputs; it does not imply statistically independent openings or players.

`neural/semantic_study.py` builds a cold declaration and implements a bounded CPU producer. The proposed workload is 3,072 standalone queries at 32,000 requested nodes and 384 all-legal MultiPV root queries at 256,000 nodes: 3,456 queries and **196,608,000 requested nodes**. Requested UCI node budgets are not promises of exact work, fixed horizon, or achieved throughput. Each worker uses one Stockfish thread and 64 MiB hash, clears hash before every query, supplies full legal game history, and disables pondering, strength limits, Chess960, and tablebases. There are two workers and a 20-second request deadline. The 1,200-second overall budget counts cold admission and startup, reserves the last ten seconds for retirement, and permits at most 1,190 seconds before work stops. This is a cooperative work/retirement bound with final monotonic acceptance checks, not a preemptive guarantee about CPU I/O or OS scheduling. Dedicated POSIX process groups own each engine. Parent TERM/INT unwind through bounded retirement, repeat cancellation is ignored during retirement, workers unmask inherited signals and close/wait their engines, and hard escalation uses a temporary Linux child-subreaper to reap only owned process groups. Original parent handlers/subreaper state are restored. The producer requires exclusive main-thread subprocess/signal ownership and unblocked cancellation signals. Per-query records and the attempt report publish by temporary-file replacement. Partial output is a closed attempt with no automatic additional queries.

The binary is the pinned official Stockfish 19 universal build, SHA256 `0f83d24cc46d2c66c60f16001af5444873bc112b7d028594513426894c12da19`; its GPL source/COPYING/release provenance are retained by the repository's match-tools installation. UCI options and command semantics follow the [official Stockfish documentation](https://official-stockfish.github.io/docs/stockfish-wiki/UCI-Protocol-and-Stockfish-Commands.html). Before real search, declaration validation rechecks the actual binary, executable module hashes, full admission and query-plan hashes, ordered spent-report bytes, options, budgets, and model/data contract. The tracked [draft](../neural/evidence/semantic-study-label-draft-2026-10-01.json) is deliberately unsealed and cannot authorize the producer.

A full-action label uses the last complete ordered rank1..K packet at one reported depth, with minimum depth six. An incomplete newer packet cannot mix with stale same-depth ranks. Every legal action must appear exactly once; every PV continuation must remain legal. Mate, upper/lower bounds, nonmonotonic rank scores, tablebase hits/reserved decisive CP scores, and incomplete or shallow support reject the query. A game is retained for the later comparison only when all eight standalone queries and its entire root pass within a fully successful attempt. Complete query files cannot override a failed worker or abnormal engine close: every partial/faulty attempt quarantines all outputs, and mechanical family completeness is recorded only for diagnosis. No replacement games are drawn after scores are observed. Reported common depth is a packet-admission condition, **not proof of exact minimax or equal selective child horizons**.

The label schema keeps separate query kinds: `stockfish_standalone_root_normalized_cp` and `stockfish_parent_root_normalized_action_cp`. [SF19's to_cp](https://github.com/official-stockfish/Stockfish/blob/sf_19/src/uci.cpp) normalizes ordinary scores by the search root's total phase material. The [pinned conversion](../neural/score_frames.py) recovers an approximate common reference-material58 midpoint `reported_cp * a(query_root_material) / a(58)` and a rounding interval. Parent MultiPV uses **parent material first, then negation** for the child-mover label. Standalone queries use their actual current/root material and retain current-mover sign. Raw UCI CP, material counts, polynomial/source pins, sign, interval, PV/depth/nodes and query budget remain attached. [SF19 score classification](https://github.com/official-stockfish/Stockfish/blob/sf_19/src/score.cpp) separates ordinary, tablebase and mate scores; this pipeline admits only the ordinary branch.

Stockfish internally removes ineffective en passant targets when rebuilding the position; stored schema1 observations retain the raw FEN target. Full legal move-history equivalence is checked, but this is not a claim of a byte-identical teacher feature packet.

This conversion does not recover exact internal values, erase search-context differences, or create calibrated outcomes. Standalone value pretraining and parent-action transition supervision have different contexts/workloads even in common units. Their discrepancy must be reported through frozen-anchor child refresh versus parent-action labels. Scalar regression must consume the converted midpoint plus interval halfwidth; it must not silently reinterpret the old material proxy or three-logit outputs as WDL.

After separate GPU admission, the native arena will rebuild each root from its one-time CPU FEN/history ingress and export all legal parent-to-child records into Torch-owned compact GPU tensors. CPU UCI labels are explicitly uploaded once as score/interval sidecars and joined by canonical action, game/root identity, hashes, and complete legal support. Feature decode, sampling, losses, and backward then remain device resident. This is **CPU label ingress**, not a claim that Stockfish produced labels directly in VRAM. No dense CPU feature corpus is required. This later ingress/learning path has not yet run in this stage.

The permission-boundary continuation copies the required package, exactly seven old spent reports, semantic docs/admissions, and source/license snapshots into `results/neural-staging` in the main checkout. Only that permitted copy receives the lifecycle fixes and regenerated declaration. The historical neural sibling and Git metadata remain unchanged. CPU execution uses the existing readable `chen-neural/results/qa-cpu-venv` interpreter (Torch2.10 CPU and chess1.11.2); Torch is an explicit CPU producer dependency. There is no Docker or GPU execution in this milestone.

Frozen staged verification: 23 targeted CPU tests passed, including independent Python-chess semantics, reporting intervals, causal prediction, restricted checkpoints, family admission, fabricated-UCI complete packets, work deadlines, crashed-worker orphan reaping, repeated parent TERM/INT, worker signal-mask reset, and abnormal final engine close after all rows were written. The cancellation exception deliberately inherits RuntimeError: local Python selectors catch InterruptedError as a retry, which was exposed by the initial failed cancellation regression and corrected before any real teacher searches. These tests use fabricated UCI fixtures and do not measure teacher quality, GPU throughput, or learned strength.
