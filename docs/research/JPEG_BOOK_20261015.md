# Half-second Hybrid Chen versus configured-1800 Stockfish, books on both sides

The book-on color pair finished **1–1**: Hybrid Chen lost as White in 136 plies
and won as Black in 64. Both games ended in checkmate. Both engines receive
0.5 seconds per searched move, one CPU thread and 16 MiB hash. Stockfish 19 uses
`UCI_LimitStrength=true`, `UCI_Elo=1800`; books do not change that configuration.
No engine executable, search settings or web deployment changed for this test.

Stockfish has no native opening-book UCI option in the tested binary. The match
controller supplies **the same book to both players**, as a GUI commonly does.
It uses the five pinned CC0 Lichess ECO TSV files already bundled with Chen,
revision `a6189a30dc273ccb21fc2536a9a2fefd5592a67a`. The shared graph contains
3,865 authored lines, projected to a maximum of twelve plies. A fixed seed
20261015 selects weighted moves deterministically from each position.

In this selected line the book runs out after seven plies:

```
1. c4 Nf6 2. Nc3 g6 3. Nf3 Bg7 4. e4
```

The engines then search normally. Both colors use that identical opening;
across the pair, each engine receives seven book moves. Book choices are
marked explicitly in the move traces and PGN comments, with zero search nodes.
Full move history is passed into subsequent engine searches. This is a shared
controller book, not a claim that the binaries themselves load native books.

Independent replay passes **both games / 200 legal plies**: PGN/JSON/FEN agreement,
exact rule outcomes, unchanged executables, book-file hashes, and every book
choice recomputed from the declared selection rule. The audit verifies book
attribution for both engines; a deliberately false book flag is rejected.
The updated auditor also passes the earlier book-off run. Four collector tests
pass, including book use by both players, the cutoff, and complete search history
after the book ends. No failures, caps or moves exceeding the 100 ms transport
allowance occurred. Maximum wall times were 466.6 ms for Chen and 555.7 ms for
Stockfish, including transport and scheduling.

This tiny pair does not establish a rating or whether books improve either
engine. The shared opening differs from the earlier authored-opening screen.

```sh
  --max-plies 512 --book-dir results/jpeg-book-both-20261015/book \
  --book-plies 12 --book-seed 20261015 --out results/new-book-pair
```
