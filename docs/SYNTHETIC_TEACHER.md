# Reachable TRAIN strategic teacher pilot

`neural/synthetic_teacher.py` collects complete-root Stockfish 19 labels separately from model inputs. The mechanics shard supplies legally replayed state/history/action support; teacher transcripts and score records live in a separate artifact tree. This pilot contains no training, GPU execution, heldout data or model comparison. Offline training is authorized separately in the broader program.

The plan is frozen before labels: 32 distinct TRAIN families, one root each, 16 White/16 Black, selected by seeded hash order with alternating movers. There are no replacements after packet outcomes. Each complete legal MultiPV query requests 262,144 nodes;8 roots chosen in advance request 1,048,576 nodes in an additional calibration query. Those 40 queries request 16,777,216 nodes. A requested budget is not exact work: retain maximum reported and selected-packet nodes separately.

The pinned official SF19 universal binary runs with Threads 1, Hash 64 MiB, full strength, no pondering/WDL/Chess960/tablebases and fixed default embedded NNUE. Setup commands and UCI identity are retained. Hash is cleared by `ucinewgame`+`isready` before every query, and full start-position move prefixes carry repetition context. CPU affinity is 4, one worker; 20 second request deadlines, 600 second cooperative bound with cleanup reserve, 660 second external process-group watchdog. Any execution fault closes the attempt without admitting the pilot; no automatic retry/resume. Missing labels under the packet policy remain measured yield, not execution faults or permission to relax the protocol.

The strict parser is copied **verbatim** from the source-bound audited [ordinary-packet-v2 preparation](../../chen/docs/research/evidence/semantic-packet-v2-preparation-2026-10-01/neural/ordinary_packets.py), SHA256 `4e6d7e9461fe0c001622acb39f5be48d461c95e1994526f9ca48f09a27cbd83f`. `teacher_session.py` extracts the existing audited `StockfishSession`, `GamePosition` and hashing blocks unchanged. No old untracked semantic drafts are modified. The [ordinary-score packet contract](../../chen/docs/research/ORDINARY_SCORE_PACKETS.md) defines admission:

- Rank 1 starts an emission; finalize at the next rank 1 or end, never immediately at rank K. Never splice emissions.
- Eligible packets cover every legal root action exactly once, have one reported depth ≥6 and one node count, legal full PVs, nonincreasing ordinary CP scores and no bounds.
- Pick highest eligible common depth, with latest completion ordinal breaking ties. The final `bestmove` is a distinct retained observation.
- Clean incomplete, mixed-depth, bounded or shallow emissions are ineligible. Corrupt grammar/ranks/support/PVs/scores reject the query. Any mate/tablebase/reserved decisive CP evidence anywhere rejects ordinary targets, even if an earlier packet was eligible.

Every emission, typed score, missing reason, selected packet identity, option command and final choice is retained. Mate distances and upper/lower bounds are typed evidence, never ordinary point labels. Accepted ordinary scores convert through existing pinned SF19 root-material normalization into reference-material 58 intervals **without negation**: all action scores use the queried parent mover frame. Intervals cover UCI rounding, not uncertainty about search error or exact minimax. Exact child standalone queries would be a different contract.

The 8 preselected calibration roots compare base versus 4× admitted packets: first canonical maximizer, choice changes, all unordered action-pair reversals/tie changes, depths and support. Missing paired packets remain noncomparable. This measures teacher stability and generation cost, not learned quality. Concurrent CPU search may share package power/cache; generation wall time is observed worker throughput under those conditions, not a clean microbenchmark.

The collector imports no model. `prepare` saves the plan, hashes source/binary/options, and exports the embedded default net once for its full hash using only metadata commands. Net bytes need not be duplicated because the pinned binary reproduces them. `run` requires the reviewed declaration SHA, cold-verifies source/data/plan/options and refuses an existing attempt directory. Focused fabricated fixtures cover deterministic selection under family-order changes, TRAIN exclusivity, full legal support, parent-frame conversion, bounded final output, emission corruption/decisive rejection and calibration ties.

The pilot supports a later declared converged [scaling comparison](SCALING_STUDY.md). It supplies no architecture winner or fitted scaling exponent. The broader [synthetic data program](../../chen/docs/research/SYNTHETIC_DATA_PROGRAM.md) governs new data increments and teacher-quality checks before expanded learning.

## Closed pilot result

The one frozen attempt completed all 40 queries, admitting 21/32 base roots with 410 distinct action rows and 3/8 calibration packets with 65 repeated-root rows. All 16 missing packets had decisive-score evidence; no roots were replaced. Base packet depths ranged 9–18. Among the 3 ordinary paired roots, 1 selected-packet canonical maximizer changed and 58/729 action pairs reversed strictly (60 changed including ties). The final UCI `bestmove` changed 0/8: historical ordinary-packet targets and final search choices are distinct. These small calibration counts do not certify teacher convergence.

The query-generation interval was 18.02 seconds, including engine setup/queries/cleanup, excluding cold plan/source admission and metadata export. Requests totaled 16,777,216 nodes; summed maximum reported score-line nodes were 16,314,458 and selected accepted-packet nodes 4,659,174. These are different telemetry quantities. All owned processes retired. All40 saved records mechanically replayed with the same frozen parser/frame code; that is a reproducibility check, not an independent implementation. The [evidence archive](../neural/evidence/synthetic-teacher-pilot-2026-10-03/README.md) retains the exact plan, declarations, source, transcripts, typed scores, support, missing reasons and complete calibration details.
