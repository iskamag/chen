# Stronger representations before strategic prediction

The preceding [strategic study](STRATEGIC_STUDY.md) selected no model under its joint calibration/ranking gate. Its fixed encoder target was random, and its shallow teacher/game population was insufficient evidence for a strategic representation. The new stage uses independently held-out real game families and proposes stronger finite-node teacher labels. The [data protocol](SEMANTIC_DATA.md) now has verified archive, actual admitted families, mover-balanced observations, complete sibling supports, and a cold **draft** label declaration. No real labels or training have been produced.

The implemented [semantic anchor and transition](SEMANTIC_STRATEGY.md) preserve square/relation/plan backends and add a typed blocked-attack/support object encoder. All four encode observations into eight plan tokens and share board, rule-state, diagram-map, and common-frame scalar decoders. Diagram targets describe blocked pseudoattacks, pressure around kings, attacked undefended nonking pieces, and one-step pawn-advance destinations. These are declared mechanical semantics, not winning threats, legality predictions, or outcomes.

The proposed causal experiment first trains an anchor on **train-family observations only**, using semantic reconstruction plus ordinary standalone search values. A matched value-only pretraining control measures whether diagram/board/rule supervision provides useful representation rather than simply more scalar optimization. The original pawn100 material baseline remains visible. A single positive material scale is fitted using train standalone labels only and shared across every later model/control; no validation or test score may choose its coefficients. Converted teacher intervals enter the scalar loss explicitly. No random encoder is described as a learned semantic target.

After pretraining, the anchor and its scalar/semantic decoders freeze. A legal-action transition predicts successor plans from a cached root representation, canonical action, and exactly derived child piece/diagram priors. The conditioned and role-transport models receive **the same** derived child inputs and action event; only role-biased routing differs. An action-blind learned correction is computed once per root and expanded across siblings, while exact child material remains action dependent. This avoids the previous duplicate-root floating-point tie artifact. Controls have different active parameter costs, which must be reported rather than assumed equal.

Training targets may include observed successor features only in the frozen target/semantic-supervision branch. Prediction accepts no successor observation. All root siblings must retain complete legal support and the child-mover sign: action selection minimizes child value, whereas teacher parent PV scores were converted using parent material before negation. Terminal/mate/history-sensitive coverage remains an explicit simulator and label-admission responsibility.

The eventual comparison must report anchor semantic reconstruction, standalone value calibration, frozen full-child refresh against parent-action search labels, predicted transition calibration, same-material sibling directions, root action regret, and action-shuffle interventions preserving true material. Refresh error separates imperfect pretrained calibration and search-context differences from additional transition error. Matching scalar units does not equate the standalone 32k and parent MultiPV 256k searches or their selective horizons.

Architecture/control seeds, pretraining and transition steps, losses, root sampling streams, positive-scale fitting algorithm, minimum retained coverage, validation gate, and test-opening seal still need a separate final learning declaration. The current draft pins width32/depth1 source/model admission but explicitly sets training authorization false. No value/architecture selection may inspect fresh test metrics. Family-based uncertainty should accompany seed summaries; two or three seeds are correlated optimization repeats, not independent samples of the chess population. Neither teacher agreement nor a semantic decoder establishes playing strength or progress toward 2500 Lichess without subsequent controlled engine matches.

The ready milestone is CPU data/protocol and model semantics. The next authorized sequence is: root review and seal bounded label production; produce or close its exact CPU attempt; admit actual complete family coverage; declare the finite learning comparison; verify native GPU joins/device paths; run the frozen comparison; seal validation selection; finally open test metrics once. There is no automatic search, GPU job, or training triggered by importing these modules or generating the draft.
