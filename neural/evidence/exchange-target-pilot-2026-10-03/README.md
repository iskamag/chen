# Closed restricted-exchange TRAIN pilot

Full source shard: 256 TRAIN families, 1,940 roots, 3,864 complete legal initial
capture/promotion actions. No learner, teacher engine, Torch or GPU executed.
Target gzip SHA256 `44fd685f66416cd517d89114f4cf05cacbc235a94bf94117286352d86933ac35`.

`declaration.json` pins source/shard/limits before label traversal. `source/`
preserves the executed generator, exact rules helpers and eight focused fixtures;
`freeze.json` binds these bytes. `targets.jsonl.gz` preserves family/full replay,
complete action support, typed missing outcomes and supervised branch traces.
`report.json` and `run.*.log` preserve terminal yield/timing; `runtime.json`
records CPU 3, the bounded invocation and actual exit 0.

The pilot closed 3,175 exact restricted targets, with 1,344 recapture continuations.
1,172 returns differ from immediate material delta (465,080 total absolute CP
difference). 604 actions need an off-destination check evasion;85 have actual typed
terminals: 69 insufficient material, 15 checkmates, 1 stalemate. No caps exhausted.
The source includes 15 initial EP actions and 672 promotions. Generation took 4.404 seconds
and entered 7,244 states; this is observed CPU generation throughput, not engine
or neural inference performance. Complete support survives missing target masks.

`trace-diagnostics.json` checks all 3,864 initial supports and recomputes 6,323 closed
trace-node backups/signs/canonical tie decisions from saved child returns. It is
not an independent rules implementation. Eight focused CPU tests include a
separate small exhaustive no-cutoff minimax oracle, both mover orientations and
order invariance, forced recapture in check, outside evasions, king/pin legality,
EP/promotion effects, typed terminals and no-point cap/abort behavior.
